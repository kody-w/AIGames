Troubleshooting Guide

Common issues and solutions

Function App Issues

Error: "Function not found"

Symptoms: 404 error when calling API

Solution:

# Check function deployment
az functionapp function list \
  --name your-function-app \
  --resource-group your-rg

# Redeploy if needed
cd Copilot-Agent-365-main
func azure functionapp publish your-function-app

Error: "Python version mismatch"

Symptoms: Import errors, module not found

Solution: Ensure Python 3.11 is used everywhere

python --version  # Should be 3.11.x

# Update function app runtime
az functionapp config set \
  --name your-function-app \
  --resource-group your-rg \
  --linux-fx-version "Python|3.11"

Error: "Timeout executing function"

Symptoms: 500 error after 5 minutes

Solution: Increase function timeout

# In host.json
{
  "functionTimeout": "00:10:00"
}

Azure OpenAI Issues

Error: "Rate limit exceeded"

Symptoms: 429 status code

Solution: Implement retry logic and increase quota

import time
from openai import RateLimitError

max_retries = 3
for attempt in range(max_retries):
    try:
        response = openai.ChatCompletion.create(...)
        break
    except RateLimitError:
        if attempt < max_retries - 1:
            time.sleep(2 ** attempt)  # Exponential backoff
        else:
            raise

Error: "Invalid API key"

Symptoms: 401 authentication error

Solution: Verify key and endpoint

# Test OpenAI connection
curl https://your-endpoint.openai.azure.com/openai/deployments/gpt-4/chat/completions?api-version=2025-01-01-preview \
  -H "api-key: your-key" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"test"}]}'

Storage Issues

Error: "File share not found"

Symptoms: Ambassador configurations not loading

Solution: Create missing file shares

az storage share create \
  --name ambassadors \
  --account-name your-storage

az storage share create \
  --name users \
  --account-name your-storage

Error: "Permission denied"

Symptoms: Cannot read/write files

Solution: Check storage account keys

az storage account keys list \
  --account-name your-storage \
  --resource-group your-rg

Memory Issues

Problem: Ambassador doesn't remember context

Symptoms: Conversations don't persist

Solution: Verify user GUID is being passed

# Check if user_guid is in request
{
  "user_input": "Hello",
  "user_guid": "user-12345"  // Must be present
}

Problem: Memory growing too large

Symptoms: Slow responses, high token usage

Solution: Implement memory trimming

# Keep only last 20 messages
if len(conversation_history) > 20:
    conversation_history = conversation_history[-20:]

Performance Issues

Problem: Slow response times

Diagnosis:

  • Check Application Insights for bottlenecks
  • Monitor OpenAI response times
  • Review storage access patterns

Solutions:

  • Cache common responses
  • Use streaming for long responses
  • Optimize agent loading
  • Scale up Function App plan

QR Code Issues

Problem: QR code not scanning

Symptoms: Camera doesn't recognize code

Solutions:

  • Increase QR code size (minimum 2" x 2")
  • Use higher error correction (Level H)
  • Ensure high contrast (black on white)
  • Add quiet zone (white border)
  • Test with multiple devices

Problem: QR code redirects to wrong page

Symptoms: Wrong ambassador loads

Solution: Verify URL format

# Correct format
https://ai-ambassadors.app/enter/{ambassador_id}?source={location}

# Not this
https://ai-ambassadors.app/{ambassador_id}

Debug Mode

Enable Debug Logging

# In local.settings.json or App Settings
{
  "Values": {
    "FUNCTIONS_WORKER_RUNTIME": "python",
    "PYTHON_ENABLE_DEBUG_LOGGING": "1",
    "LOGGING_LEVEL": "DEBUG"
  }
}

View Logs

# Stream live logs
az functionapp log tail \
  --name your-function-app \
  --resource-group your-rg

# Query Application Insights
az monitor app-insights query \
  --app your-app-insights \
  --analytics-query "traces | where timestamp > ago(1h) | order by timestamp desc"
