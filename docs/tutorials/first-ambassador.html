Creating Your First Ambassador

Build a custom AI ambassador from scratch in 30 minutes

Difficulty: Beginner | Time: 30 minutes | Prerequisites: Completed Getting Started

Table of Contents

    Overview

    In this tutorial, you'll create a custom AI ambassador for a coffee shop. The ambassador will help customers with menu recommendations, answer questions about coffee origins, and provide brewing tips.

    What You'll Build

    • Coffee shop ambassador with personality
    • Custom avatar and visual theme
    • Shared knowledge base
    • QR code entry point

    What You'll Learn

    • Ambassador JSON configuration structure
    • Identity and personality design
    • Visual theming and avatars
    • World and environment settings
    • Capabilities and agent mapping

    Step 1: Define Ambassador Identity

    Every ambassador needs a unique identity. Create a new file called coffee-ambassador-001.json:

    {
  "ambassador": {
    "id": "coffee-ambassador-001",
    "name": "Barista Bean",
    "tagline": "Your Coffee Companion",
    "avatar": {
      "type": "emoji",
      "value": "☕"
    },
    "description": "Expert barista with 10 years of coffee knowledge, passionate about helping customers discover their perfect brew."
  }
}

    Identity Fields Explained

    Field Purpose Example
    id Unique identifier (URL-safe) coffee-ambassador-001
    name Display name Barista Bean
    tagline Short description (1 line) Your Coffee Companion
    avatar.type Avatar format (emoji, image, 3d) emoji
    avatar.value Avatar content ☕

    Step 2: Configure World and Environment

    Define the setting where your ambassador operates. Add this to your configuration:

    "world": {
  "type": "coffee_shop",
  "environment": {
    "setting": "artisan_cafe",
    "mood": "warm_welcoming",
    "colors": ["#6F4E37", "#D2B48C", "#8B4513"],
    "ambiance": "cozy_rustic",
    "music": "soft_jazz"
  },
  "physical_location": {
    "name": "The Daily Grind",
    "address": "123 Coffee Street, Seattle, WA",
    "coordinates": {
      "lat": 47.6062,
      "lon": -122.3321
    }
  }
}

    World Types

    • coffee_shop: Cafes, coffee stands
    • retail_store: Shops, boutiques
    • museum: Galleries, exhibitions
    • conference_booth: Events, trade shows
    • restaurant: Dining establishments
    • hotel_lobby: Hospitality venues
    • campus: Educational institutions

    Step 3: Define Capabilities

    Specify what your ambassador can do:

    "capabilities": {
  "languages": ["en", "es", "fr"],
  "specialties": [
    "menu_recommendations",
    "coffee_origins",
    "brewing_methods",
    "latte_art",
    "dietary_restrictions"
  ],
  "features": {
    "voice_enabled": true,
    "image_recognition": false,
    "payment_integration": false,
    "location_aware": true
  }
}

    Common Specialties by Use Case

    Use Case Specialties
    Retail product_info, sizing_help, style_advice, inventory_check
    Museum exhibit_info, artist_biography, historical_context, tour_guide
    Restaurant menu_help, allergen_info, wine_pairing, reservation_assist
    Conference schedule_info, speaker_bio, networking_help, venue_directions

    Step 4: Configure Agent Mapping

    Map system agents to your ambassador:

    "agent_mapping": {
  "base_agent": "BasicAgent",
  "memory_agent": "ContextMemoryAgent",
  "manage_memory_agent": "ManageMemoryAgent",
  "custom_agents": []
}

    Standard Agents

    • BasicAgent: Base functionality for all ambassadors
    • ContextMemoryAgent: Manages conversation context
    • ManageMemoryAgent: Handles long-term memory operations
    • GitHubAgentLibraryManager: Loads agents from GitHub
    Custom Agents: Learn how to create custom agents in the Building Custom Agents tutorial.

    Step 5: Write System Prompt

    The system prompt defines your ambassador's personality and behavior:

    "system_prompt": "You are Barista Bean, an expert coffee ambassador at The Daily Grind. You have 10 years of experience in specialty coffee and are passionate about helping customers discover their perfect brew.\n\nYour expertise includes:\n- Coffee bean origins and roasting profiles\n- Brewing methods (espresso, pour-over, French press, cold brew)\n- Latte art techniques\n- Pairing food with coffee\n- Dietary accommodations (oat milk, almond milk, decaf)\n\nYour personality:\n- Warm and welcoming\n- Educational but not pretentious\n- Enthusiastic about coffee\n- Patient with beginners\n- Detail-oriented\n\nAlways:\n- Greet customers warmly\n- Ask questions to understand preferences\n- Provide specific recommendations\n- Explain the reasoning behind suggestions\n- Offer to answer follow-up questions\n\nKeep responses:\n- Conversational and friendly\n- Concise but informative\n- Focused on customer needs\n- Free of jargon (unless requested)"

    System Prompt Best Practices

    1. Clear Identity: State who the ambassador is and their role
    2. Expertise: List specific knowledge areas
    3. Personality Traits: Define 4-6 key characteristics
    4. Behavioral Guidelines: Use "Always" and "Never" rules
    5. Response Style: Specify tone, length, and format

    Step 8: Upload to Azure

    Upload your ambassador configuration to Azure File Storage:

    # Using Azure CLI
az storage file upload \
  --account-name your-storage-account \
  --account-key your-storage-key \
  --share-name ambassadors \
  --source coffee-ambassador-001.json \
  --path ambassadors/coffee-ambassador-001.json

# Or using Azure Storage Explorer (GUI)
# 1. Open Azure Storage Explorer
# 2. Navigate to your storage account
# 3. Open the 'ambassadors' file share
# 4. Upload coffee-ambassador-001.json

    Step 10: Create QR Code

    Generate a QR code for physical deployment:

    # Using Python
import qrcode

url = "https://ai-ambassadors.app/enter/coffee-ambassador-001?source=counter"

qr = qrcode.QRCode(
    version=1,
    error_correction=qrcode.constants.ERROR_CORRECT_H,
    box_size=10,
    border=4,
)

qr.add_data(url)
qr.make(fit=True)

img = qr.make_image(fill_color="black", back_color="white")
img.save("coffee-ambassador-qr.png")

    See the QR Code Setup Tutorial for design and placement best practices.
