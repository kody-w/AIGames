Building Custom Agents

Extend ambassador capabilities with Python agents

Agent Template

from agents.basic_agent import BasicAgent

class CoffeeInventoryAgent(BasicAgent):
    def __init__(self):
        self.name = 'CoffeeInventory'
        self.metadata = {
            "name": self.name,
            "description": "Check coffee bean inventory levels",
            "parameters": {
                "type": "object",
                "properties": {
                    "bean_type": {
                        "type": "string",
                        "description": "Type of coffee bean"
                    }
                },
                "required": ["bean_type"]
            }
        }
        super().__init__(self.name, self.metadata)

    def perform(self, **kwargs):
        bean_type = kwargs.get('bean_type', '')
        
        # Mock inventory check
        inventory = {
            "ethiopian": 25,
            "colombian": 40,
            "brazilian": 15
        }
        
        stock = inventory.get(bean_type.lower(), 0)
        
        if stock > 20:
            return f"Good news! We have plenty of {bean_type} in stock ({stock} lbs)."
        elif stock > 0:
            return f"We have limited {bean_type} available ({stock} lbs)."
        else:
            return f"Sorry, {bean_type} is currently out of stock."

Agent Structure

  • __init__: Define name and metadata (function definition)
  • perform: Execute agent logic with kwargs
  • metadata: OpenAI function definition format

Deploying Custom Agents

# Local deployment
cp coffee_inventory_agent.py Copilot-Agent-365-main/agents/

# Azure deployment
az storage file upload \
  --account-name your-storage \
  --share-name agents \
  --source coffee_inventory_agent.py \
  --path agents/coffee_inventory_agent.py

Testing Agents

from agents.coffee_inventory_agent import CoffeeInventoryAgent

agent = CoffeeInventoryAgent()
result = agent.perform(bean_type="Ethiopian")
print(result)  # "Good news! We have plenty of Ethiopian in stock (25 lbs)."
