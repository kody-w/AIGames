Setting Up QR Codes

Bridge physical and digital worlds with QR codes

QR Code URL Pattern

https://ai-ambassadors.app/enter/{ambassador_id}?source={location}

Example URLs

https://ai-ambassadors.app/enter/coffee-ambassador-001?source=counter
https://ai-ambassadors.app/enter/museum-guide-art-wing?source=gallery-3
https://ai-ambassadors.app/enter/retail-assistant-main?source=entrance

QR Code Generation

import qrcode

qr = qrcode.QRCode(
    version=1,
    error_correction=qrcode.constants.ERROR_CORRECT_H,
    box_size=10,
    border=4,
)

url = "https://ai-ambassadors.app/enter/coffee-ambassador-001?source=counter"
qr.add_data(url)
qr.make(fit=True)

img = qr.make_image(fill_color="black", back_color="white")
img.save("qr-code.png")

Design Requirements

  • Size: Minimum 2" x 2" for reliable scanning
  • Contrast: High contrast (black on white recommended)
  • Error Correction: Level H (30% recovery) for durability
  • Quiet Zone: Clear border around code
  • Material: Weather-resistant if outdoors
