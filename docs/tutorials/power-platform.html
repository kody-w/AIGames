AI Ambassador

Power Platform Integration

Integrate with Microsoft Teams and Microsoft 365 Copilot

Prerequisites

  • Microsoft 365 subscription
  • Power Platform license
  • Azure subscription
  • Deployed AI Ambassador Platform

Teams Bot Setup

# Install Bot Framework
npm install -g @microsoft/generator-botframework

# Create Teams app
yo botframework --template=teams

# Configure endpoint
"messagingEndpoint": "https://your-function-app.azurewebsites.net/api/teams_endpoint"

Microsoft 365 Copilot Integration

Ambassadors can be deployed as Microsoft 365 Copilot plugins for enterprise use. See official documentation for plugin development.
