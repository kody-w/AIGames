Creating Seeded Demos

Build reproducible demo experiences with synthetic memory

What Are Seeded Demos?

Seeded demos use synthetic memory to create reproducible experiences for sales presentations, trade shows, and testing.

Use Cases

  • Sales presentations with consistent narratives
  • Trade show demonstrations
  • User onboarding walkthroughs
  • Testing and development

Demo Initialization

def initialize_seeded_demo(ambassador_id, demo_guid):
    """Load synthetic memory for demo"""
    config = load_ambassador_config(ambassador_id)
    
    if config['demo_configuration']['seeded_run']:
        synthetic_memory = config['demo_configuration']['synthetic_memory']
        storage_manager = AzureFileStorageManager()
        storage_manager.set_memory_context(demo_guid)
        
        for memory in synthetic_memory['memories']:
            storage_manager.write_memory(memory['id'], memory)
    
    return config
