Table of Contents

    Base URL

    Production: https://your-function-app.azurewebsites.net/api
Development: http://localhost:7071/api

    Authentication

    API requests require a function key for authorization:

    x-functions-key: your-function-key-here
    Security: Never expose function keys in client-side code. Use Azure AD authentication for production.

    Chat Endpoint

    POST /businessinsightbot_function

    Send a message to an AI ambassador and receive a response.

    Request Body

    {
  "user_input": "string (required)",
  "conversation_history": "array (optional)",
  "user_guid": "string (optional)",
  "ambassador_id": "string (optional)"
}

    Parameters

    ParameterTypeRequiredDescription
    user_input string Yes User's message or question
    conversation_history array No Previous messages in conversation
    user_guid string No Unique user identifier for memory isolation
    ambassador_id string No Specific ambassador to use

    Example Request

    curl -X POST https://your-function-app.azurewebsites.net/api/businessinsightbot_function \
  -H "Content-Type: application/json" \
  -H "x-functions-key: your-key" \
  -d '{
    "user_input": "What coffee do you recommend?",
    "conversation_history": [],
    "user_guid": "user-12345",
    "ambassador_id": "coffee-ambassador-001"
  }'

    Response

    {
  "response": "I'd recommend our Ethiopian Yirgacheffe for a bright, floral experience...|||VOICE|||Try our Ethiopian coffee for a fruity flavor!",
  "conversation_history": [
    {
      "role": "user",
      "content": "What coffee do you recommend?"
    },
    {
      "role": "assistant",
      "content": "I'd recommend our Ethiopian Yirgacheffe..."
    }
  ],
  "user_guid": "user-12345",
  "tokens_used": 245
}

    Response Fields

    FieldTypeDescription
    response string Ambassador response (formatted|||VOICE|||voice-optimized)
    conversation_history array Updated conversation including new messages
    user_guid string User identifier used for this request
    tokens_used integer OpenAI tokens consumed

    Ambassador Entry Endpoint

    GET /ambassador_entry

    Initialize a session when a user scans a QR code.

    Query Parameters

    ParameterTypeRequiredDescription
    ambassador_id string Yes Ambassador identifier
    source string No Physical location identifier

    Example Request

    curl https://your-function-app.azurewebsites.net/api/ambassador_entry?ambassador_id=coffee-ambassador-001&source=counter

    Response

    {
  "ambassador": {
    "id": "coffee-ambassador-001",
    "name": "Barista Bean",
    "avatar": {"type": "emoji", "value": "☕"},
    "greeting": "Welcome! I'm Barista Bean, ready to help you find your perfect coffee!"
  },
  "session_id": "sess-abc123",
  "user_guid": "user-xyz789"
}

    Memory Management

    GET /memory/{user_guid}

    Retrieve user memory

    curl https://your-function-app.azurewebsites.net/api/memory/user-12345 \
  -H "x-functions-key: your-key"

    POST /memory/{user_guid}

    Store user memory

    curl -X POST https://your-function-app.azurewebsites.net/api/memory/user-12345 \
  -H "Content-Type: application/json" \
  -H "x-functions-key: your-key" \
  -d '{
    "memory_id": "pref_001",
    "type": "preference",
    "content": "Prefers dark roast",
    "timestamp": "2025-01-15T10:00:00Z"
  }'

    DELETE /memory/{user_guid}/{memory_id}

    Delete specific memory

    curl -X DELETE https://your-function-app.azurewebsites.net/api/memory/user-12345/pref_001 \
  -H "x-functions-key: your-key"

    Webhooks

    Configure webhooks to receive real-time notifications for events.

    Supported Events

    • conversation.started: New conversation initiated
    • conversation.completed: Conversation ended
    • user.feedback: User provided feedback
    • error.occurred: Error during processing

    Webhook Payload

    {
  "event": "conversation.started",
  "timestamp": "2025-01-15T10:30:00Z",
  "data": {
    "user_guid": "user-12345",
    "ambassador_id": "coffee-ambassador-001",
    "source": "counter"
  }
}

    SDKs and Libraries

    Python

    pip install ai-ambassador-sdk

from ai_ambassador import AmbassadorClient

client = AmbassadorClient(
    base_url="https://your-function-app.azurewebsites.net/api",
    api_key="your-key"
)

response = client.chat(
    user_input="What coffee do you recommend?",
    user_guid="user-12345"
)

print(response.message)

    JavaScript

    npm install @ai-ambassador/sdk

import { AmbassadorClient } from '@ai-ambassador/sdk';

const client = new AmbassadorClient({
  baseUrl: 'https://your-function-app.azurewebsites.net/api',
  apiKey: 'your-key'
});

const response = await client.chat({
  userInput: 'What coffee do you recommend?',
  userGuid: 'user-12345'
});

console.log(response.message);
