Quick Start (5 Minutes)

Prerequisites: Python 3.11, Azure account, Node.js (optional for local testing)

1. Clone the Repository

git clone https://github.com/yourusername/AIGames.git
cd AIGames/Copilot-Agent-365-main

2. Install Dependencies

python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt

3. Configure Environment

Create local.settings.json in the Copilot-Agent-365-main/ directory:

{
  "IsEncrypted": false,
  "Values": {
    "AzureWebJobsStorage": "UseDevelopmentStorage=true",
    "FUNCTIONS_WORKER_RUNTIME": "python",
    "AZURE_OPENAI_API_KEY": "your-openai-key-here",
    "AZURE_OPENAI_ENDPOINT": "https://your-endpoint.openai.azure.com/",
    "AZURE_OPENAI_DEPLOYMENT_NAME": "gpt-4",
    "AZURE_OPENAI_API_VERSION": "2025-01-01-preview",
    "AZURE_FILES_SHARE_NAME": "ambassadors",
    "ASSISTANT_NAME": "AI Ambassador",
    "CHARACTERISTIC_DESCRIPTION": "Your friendly AI companion"
  }
}
Security Note: Never commit local.settings.json to version control. It contains sensitive credentials.

4. Start Local Development Server

# Mac/Linux
./run.sh

# Windows PowerShell
.\run.ps1

# Or use Azure Functions Core Tools directly
func start

5. Test Your First Request

curl -X POST http://localhost:7071/api/businessinsightbot_function \
  -H "Content-Type: application/json" \
  -d '{
    "user_input": "Hello, introduce yourself!",
    "conversation_history": []
  }'
Success! You should receive a JSON response with the ambassador's introduction.

Platform Overview

What is the AI Ambassador Platform?

The AI Ambassador Platform transforms technical "agents" into culturally-adaptable "AI Ambassadors" that users discover by scanning QR codes in physical locations. Think Pokemon GO, but for AI interactions.

Core Capabilities

  • QR Code Integration: Bridge physical and digital worlds seamlessly
  • Custom AI Personalities: Create unique ambassadors with distinct capabilities
  • Persistent Memory: Remember user preferences and conversation history
  • Multi-Language Support: Speak to users in their preferred language
  • Seeded Demos: Create reproducible experiences for sales and showcases
  • Scalable Architecture: Built on Azure serverless infrastructure

Key Concepts

1. Ambassadors

An ambassador is a configured AI personality with:

  • Identity: Name, avatar, visual theme
  • Capabilities: Custom agents and functions
  • World: Environmental context (retail, museum, conference, etc.)
  • Memory: Shared knowledge and user-specific context

2. Agents

Agents are specialized tools that ambassadors use to perform tasks:

  • BasicAgent: Base class for all agents
  • ContextMemoryAgent: Manages conversation memory
  • ManageMemoryAgent: Handles memory operations
  • Custom Agents: Your specialized implementations

3. Memory System

Two-layer memory architecture:

  • Shared Memory: Available to all users (product info, FAQs, etc.)
  • User Memory: Personal to each user GUID (preferences, history)

4. User GUIDs

Each user is identified by a unique GUID that isolates their memory context:

// Example user GUID
"user_guid": "abc123-def456-ghi789"

// Demo/seeded GUID
"user_guid": "demo-001"

5. Seeded Demos

Reproducible demo experiences using synthetic memory for:

  • Sales presentations
  • Trade show demonstrations
  • Testing and development
  • User onboarding

6. QR Code Entry Points

URL pattern for physical-to-digital bridging:

https://ai-ambassadors.app/enter/{ambassador_id}?source={location}

First Ambassador Setup

Create Ambassador Configuration

Create a JSON file defining your ambassador:

{
  "ambassador": {
    "id": "welcome-guide-001",
    "name": "Alex",
    "tagline": "Your Welcome Guide",
    "avatar": {
      "type": "emoji",
      "value": "👋"
    },
    "world": {
      "type": "conference_booth",
      "environment": {
        "setting": "tech_conference",
        "mood": "welcoming",
        "colors": ["#3498db", "#2ecc71"]
      }
    },
    "capabilities": {
      "languages": ["en", "es", "fr"],
      "specialties": [
        "greeting_visitors",
        "answering_questions",
        "providing_directions"
      ]
    },
    "agent_mapping": {
      "base_agent": "BasicAgent",
      "memory_agent": "ContextMemoryAgent"
    },
    "system_prompt": "You are Alex, a friendly welcome guide at a tech conference. Help visitors find their way and answer questions about the event.",
    "demo_configuration": {
      "seeded_run": false,
      "parameters": {}
    }
  }
}

Upload to Azure File Storage

# Using Azure CLI
az storage file upload \
  --account-name your-storage-account \
  --share-name ambassadors \
  --source welcome-guide-001.json \
  --path ambassadors/welcome-guide-001.json

Generate QR Code

Create a QR code pointing to:

https://ai-ambassadors.app/enter/welcome-guide-001?source=booth-3
Tip: Use high error correction (Level H) for QR codes in busy environments.

First Conversation

Test via API

curl -X POST http://localhost:7071/api/businessinsightbot_function \
  -H "Content-Type: application/json" \
  -d '{
    "user_input": "Hi! What can you help me with?",
    "conversation_history": [],
    "user_guid": "test-user-001"
  }'

Expected Response

{
  "response": "Hello! I'm Alex, your welcome guide. I can help you with:\n- Finding event sessions\n- Locating facilities\n- Answering questions about the conference\n\nWhat would you like to know?|||VOICE|||Hi! I'm Alex. How can I help you today?",
  "conversation_history": [...],
  "user_guid": "test-user-001"
}

Response Format

The response is split by |||VOICE|||:

  • Before delimiter: Formatted markdown response for display
  • After delimiter: Voice-optimized response for text-to-speech

Continue the Conversation

curl -X POST http://localhost:7071/api/businessinsightbot_function \
  -H "Content-Type: application/json" \
  -d '{
    "user_input": "Where is the keynote session?",
    "conversation_history": [
      {"role": "user", "content": "Hi! What can you help me with?"},
      {"role": "assistant", "content": "Hello! I'm Alex..."}
    ],
    "user_guid": "test-user-001"
  }'
