Administrator Guide

Platform management and administration

User Management

View All Users

az storage file list \
  --account-name your-storage \
  --share-name users \
  --output table

View User Memory

az storage file download \
  --account-name your-storage \
  --share-name users \
  --path user_{guid}/memory.json \
  --dest user-memory.json

Delete User Data (GDPR Compliance)

az storage directory delete \
  --account-name your-storage \
  --share-name users \
  --directory-name user_{guid} \
  --recursive

Ambassador Management

List All Ambassadors

az storage file list \
  --account-name your-storage \
  --share-name ambassadors \
  --output table

Update Ambassador Configuration

az storage file upload \
  --account-name your-storage \
  --share-name ambassadors \
  --source updated-ambassador.json \
  --path ambassadors/ambassador-id.json \
  --overwrite

Deactivate Ambassador

Add to configuration:

"status": "inactive",
"deactivated_at": "2025-01-15T10:00:00Z"

Security Configuration

Rotate Function Keys

az functionapp keys set \
  --name your-function-app \
  --resource-group your-rg \
  --key-name default \
  --key-value new-random-key

Configure IP Restrictions

az functionapp config access-restriction add \
  --name your-function-app \
  --resource-group your-rg \
  --rule-name allow-office \
  --action Allow \
  --ip-address 203.0.113.0/24 \
  --priority 100

Enable Azure AD Authentication

az webapp auth update \
  --name your-function-app \
  --resource-group your-rg \
  --enabled true \
  --action LoginWithAzureActiveDirectory

Monitoring and Alerts

View Application Insights

az monitor app-insights component show \
  --app your-app-insights \
  --resource-group your-rg

Configure Alert Rules

az monitor metrics alert create \
  --name high-error-rate \
  --resource-group your-rg \
  --scopes /subscriptions/{sub}/resourceGroups/{rg}/providers/Microsoft.Web/sites/{app} \
  --condition "count requests/failed > 10" \
  --window-size 5m \
  --evaluation-frequency 1m

Key Metrics to Monitor

  • Request Count: Total API requests
  • Error Rate: Failed requests percentage
  • Response Time: Average response latency
  • Token Usage: OpenAI token consumption
  • Storage Usage: Azure Files capacity

Backup and Recovery

Backup Ambassador Configurations

az storage file download-batch \
  --account-name your-storage \
  --source ambassadors \
  --destination ./backups/ambassadors-$(date +%Y%m%d)

Backup User Data

az storage file download-batch \
  --account-name your-storage \
  --source users \
  --destination ./backups/users-$(date +%Y%m%d)

Restore from Backup

az storage file upload-batch \
  --account-name your-storage \
  --destination ambassadors \
  --source ./backups/ambassadors-20250115

Enable Auto-Scaling

az monitor autoscale create \
  --resource-group your-rg \
  --resource your-function-app \
  --resource-type Microsoft.Web/serverfarms \
  --name autoscale-rule \
  --min-count 1 \
  --max-count 10 \
  --count 2
